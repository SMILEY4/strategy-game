PageInGame
	- onEnter: 	connect to game
	- onRender: render GameLoading, GameError, GamePlaying depending on current session state
	- onExit: 	-

GamePlaying
	- onEnter:	-
	- onRender:	render canvas, etc
	- onExit:	stop game, i.e. set session state to "none"

Canvas
	- onEnter:
		- set canvas handle, create webgl-context
		- initialize game renderer
			- reset change provider
			- create and initialize render graphs (create resources, compile commands)
		- start render loop
	- onRender:	-
	- onExit:
		- stop render loop
		- dispose game renderer
			- dispose render graphs (resources)
			- reset change provider
		- clear canvas handle
